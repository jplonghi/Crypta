# Public test fixture provenance

`upstream-vectors.json` was extracted from libsodium 1.0.22-RELEASE, commit
`77e1ce5d6dee871c49ef211222ba18ef0c486bda`:

- [Argon2id input](https://github.com/jedisct1/libsodium/blob/77e1ce5d6dee871c49ef211222ba18ef0c486bda/test/default/pwhash_argon2id.c), first `tv` case, 127 input bytes, first 16 salt bytes, 155 output bytes, 5 passes, 7,256,678 memory bytes (library truncates to KiB), one lane.
- [Argon2id expected output](https://github.com/jedisct1/libsodium/blob/77e1ce5d6dee871c49ef211222ba18ef0c486bda/test/default/pwhash_argon2id.exp), first line.
- [XChaCha input](https://github.com/jedisct1/libsodium/blob/77e1ce5d6dee871c49ef211222ba18ef0c486bda/test/default/aead_xchacha20poly1305.c), first `tv` case.
- [XChaCha expected output](https://github.com/jedisct1/libsodium/blob/77e1ce5d6dee871c49ef211222ba18ef0c486bda/test/default/aead_xchacha20poly1305.exp), first 130 bytes.

Upstream known-answer outputs are fixed inputs to the tests, not computed by Crypta.
See `Documentation/THIRD_PARTY_NOTICES.md` for the upstream ISC license.

`reference-v1.crypta` and `reference-payload.json` are generated by
`Scripts/reference_fixture.py`, using argon2-cffi's reference Argon2 bindings and
PyCryptodome's XChaCha20-Poly1305 implementation, independently of libsodium.
The exact Python environment is pinned in `Scripts/reference-requirements.txt`.
All keys, nonces, salts and the passphrase are public synthetic constants. The fixture
is deliberately deterministic for compatibility testing and provides no confidentiality.
